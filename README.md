# Wake Up, Aurell!

A small Spider-Man-inspired cinematic web project made for October 1st.

This project started from a simple sentence:

> "Wake me up when September ends."

Instead of just sending a message when September was over, I decided to turn it into a small cinematic experience.

The website is designed to be opened around 00:00 on October 1st, when September has officially ended.

## About

This isn't meant to be a full game. It's more like a short interactive scene with a beginning, a small story, and an ending.

The project includes:

- Main menu
- Cinematic room scene
- Character animation
- Calendar sequence
- September to October transition
- Final wake-up screen
- Background music and sound
- Spider-Man-inspired visuals

## Development

The project went through several iterations before reaching the current version.

The first attempt became too complicated, so I restarted and changed the way I worked on it. Instead of building everything at once, I separated the project into several independent parts:

- Calendar
- Room
- Main Menu
- Wake Up / Ending
- Character design

Each part was developed separately and later combined into one project.

## Tech

Built with:

- HTML
- CSS
- JavaScript
- Web assets and animations

No framework was used for the main experience.
